# API «Умная теплица»

Публичное API версии 1 отдаёт только обезличенный справочник культур, сортов и допустимых стадий роста. Персональные данные, адреса теплиц, задачи и измерения пользователей не публикуются.

Базовый адрес: `http://127.0.0.1:8000/api/v1`.

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/crops` | Культуры, сорта и стадии роста |
| GET | `/crops/{id}` | Одна культура |
| GET | `/varieties` | Сорта |
| GET | `/varieties/{id}` | Один сорт |
| GET | `/growth-stages` | Справочник стадий роста |
| GET | `/statistics` | Обезличенная статистика |
| POST | `/crops` | Создать культуру |
| PUT/PATCH | `/crops/{id}` | Изменить культуру |
| DELETE | `/crops/{id}` | Удалить культуру |
| POST | `/varieties` | Создать сорт и назначить стадии |
| PUT/PATCH | `/varieties/{id}` | Изменить сорт и стадии |
| DELETE | `/varieties/{id}` | Удалить сорт |

Параметры `search` и `per_page` доступны для культур. Для сортов также доступен `crop_id`. `per_page` принимает значения от 1 до 100. Ошибки валидации возвращаются со статусом 422, отсутствующие записи — 404.

Пример:

```bash
curl -H "Accept: application/json" "http://127.0.0.1:8000/api/v1/crops?search=томат"
```

Несовместимые изменения должны выпускаться под новым префиксом, например `/api/v2`.

Изменяющие запросы защищены ключом из `GREENHOUSE_API_KEY`. Передайте его в заголовке `X-API-Key`. Ключ нельзя хранить в клиентском JavaScript или публиковать в репозитории.
